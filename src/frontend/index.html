Provimento nº 213/2026 CNJ
Segurança & Imutabilidade (CNJ Provimento 213/2026): Esta aplicação demonstra a conformidade com as regras de prevenção contra ransomware e integridade arquivística digital. Os arquivos no bucket s3_cartorio_imultavel são protegidos por AWS S3 Object Lock (WORM), impedindo qualquer modificação ou exclusão por tempo determinado, mesmo para o administrador do sistema.

Serviços AWS Utilizados

  • AWS Lambda

    Backend serverless para geração de assinaturas e processamento automatizado de PDF.

  • Amazon S3 (Buckets Raw & Imutável)

    Armazenamento estático, buckets de arquivos com versionamento e bloqueio contra ransomware.

  • Amazon API Gateway

    Roteamento das requisições HTTP seguras com controle de CORS.

  • Amazon SNS (Simple Notification Service)

    Disparo instantâneo de alertas de auditoria e conformidade digital via e-mail.
